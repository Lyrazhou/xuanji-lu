## 关于“打开原图”

v260825E 中的“打开原图”原本意图是在新的浏览器式页面中打开图片资源，但它把 Tauri 本地 asset 地址作为普通链接交给 WebView，Windows 桌面环境可能不会对该链接作出可见反应。v260825F 已将其改为更符合独立软件体验的行为：**使用 Windows 已关联的默认图片查看器打开原始本地文件**。应用内点击缩略图本身仍负责显示放大的预览图。

## 图片另存的范围

“另存图片”面向 v260825E 及以后归档到本机的图片。少量历史记录如仍保留远端 URL 或内嵌 data URI，软件会提示其尚未归档为本地文件；重新生成该图片后即可使用本功能。图库中删除记录不会自动删除原始图片文件，避免误删用户资料。

## 安装步骤

1. 完全退出《璇玑录》，包括确认任务栏通知区域中没有仍在运行的程序。
2. 确认侧栏版本显示为 **v260825E · UTC+8**。
3. 运行 `璇玑录-v260825E-to-v260825F-Patch.exe`。
4. 补丁会备份 v260825E 主程序，写入 v260825F 主程序，并将内部版本更新为 0.1.5。SQLite 档案、图片、备份文件与 Windows 凭据不会被删除。
5. 启动软件后，确认侧栏显示 **v260825F · UTC+8**。

可通过随附的 `.sha256` 文件核对补丁下载完整性。补丁只包含新版本 `xuanji-lu.exe` 主程序，不包含新的完整安装包，也不会覆盖本地档案数据。
