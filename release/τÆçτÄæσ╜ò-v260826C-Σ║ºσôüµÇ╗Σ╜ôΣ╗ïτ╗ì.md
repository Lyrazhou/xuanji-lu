# 《璇玑录》产品总体介绍

> **当前版本**：v260826C（Windows x64）  
> **产品属性**：《星骰工作室》本地版  
> **产品主题**：血月星盘风格的占星骰子占问、训练与个人档案工作台。

## 一、产品概述

《璇玑录》是一款面向占星骰子爱好者、内容创作者与自我反思实践者的 Windows 本地桌面应用。它将一次占问从“提出问题—掷下三骰—获得解读—生成图像—记录复盘”的过程组织为连续、可保存、可检索的个人工作流，并进一步以训练场帮助用户练习解盘能力。

产品名称取自“璇玑”这一中国古典星象意象，视觉上以曜石黑、深靛、暗红与古金构成“血月星盘”主题。它不是把占卜结果视为即时消耗品，而是将每一次骰面、解读、评分、图片和回顾沉淀为个人星语档案。用户可在长期使用中观察自己关心的问题、偏好的符号与解读习惯，形成更有条理的反思路径。

> **核心主张**：把每一次掷骰、每一段星语和每一份复盘，安放在只属于你的本地观星台。

## 二、目标用户与使用场景

《璇玑录》服务于希望在本机管理占星骰子内容的用户。它适合希望保留私人案例、需要持续练习解盘、希望将 AI 作为写作与启发辅助工具，或希望将解读与视觉创作结合的人群。

| 目标用户 | 典型需求 | 《璇玑录》的支持方式 |
|---|---|---|
| 占星骰子初学者 | 了解三颗骰子的组合表达，建立解读框架 | 训练场提供问题、参考解读、亮点、改进建议与百分制评分 |
| 有经验的爱好者 | 保存案例、复盘验证、观察长期主题 | 本地档案、彩色标签、关键词搜索、分页查看与复盘字段 |
| 内容创作者 | 将骰面与主题转化为视觉或文字素材 | AI 解读、图片提示词模板、海报型输出与本地图库 |
| 注重隐私的个人用户 | 不希望把私人历史交给单一在线平台 | 数据库、图片与备份保存在本机；模型服务由用户自行选择 |
| 教学与社群组织者 | 需要可复现的案例与训练材料 | 手动指定骰面、训练案例保存、Markdown/CSV/HTML 导出 |

应用不提供模型账户、第三方服务、API 密钥或任何预置的商业模型配置。用户拥有对文字模型、生图模型、服务地址、超时参数和扩展请求参数的完全选择权。

## 三、产品理念：本地优先，模型可替换，档案可沉淀

### 本地优先的个人档案

《璇玑录》的数据库、归档图片和备份文件位于软件安装目录下的 `data` 文件夹。应用使用 SQLite 管理结构化记录，图片采用本地文件归档方式保存，避免将图片大对象直接堆积在数据库中。用户可以执行本地备份，或导出不含密钥的 SDE-1 档案包，在不同环境之间保留自己的历史内容。

### 由用户决定 AI 能力

AI 并不是《璇玑录》的账户体系，而是用户可替换的能力接口。用户可以单独创建文字处理 Profile 和生图 Profile，填写自己的 API 地址、模型名称、认证方式、超时时间和必要参数。应用将密钥存储在 Windows Credential Manager，而不将其写入档案导出包、安装补丁或普通设置文件。

### 从“问一次”到“长期练习”

占问模块强调即时的仪式与解读，训练场强调解读能力的培养，档案模块强调回望与复盘，图库模块强调视觉沉淀。四者连接起来，使应用不止于一次性结果展示，而成为一个围绕象征、语言、图像与个人经验的长期练习工具。

## 四、功能体系

### 1. 星骰占问：将问题、骰面与解读连接起来

用户输入问题后，可以自动掷骰或手动指定骰面。自动掷骰的最终结果由本地后端通过操作系统安全随机熵源独立抽取：行星骰、星座骰和宫位骰各有 12 个骰面，共构成 1,728 种完整组合。应用保留短暂的滚动动画，但动画结束时的最终骰面来自实际本地抽样。

用户配置文字 Profile 后，应用会把问题和真实骰面上下文发送给 AI，请其提供逐骰解读、综合分析和视觉提示语。生成结果会自动保存为占卜记录，并标明“自动”或“手动”来源标签。

### 2. 星语档案：把即时结果变成可检索的个人素材库

星语档案集中保存占问记录与训练案例。用户可以按关键词检索，使用多个标签进行“与”关系过滤，查看每条案例的完整内容，并填写复盘验证和个人评分。档案支持 CSV、HTML 与 Markdown 导出，便于留存、整理或二次创作。

系统标签“自动”“手动”“图片”用于忠实记录案例来源和图片状态。它们会显示在案例上、可用于过滤，但不能被用户误删或编辑；自定义标签则由用户自由创建、使用与管理。

### 3. 训练场：让解盘能力形成可见的进步轨迹

训练场采用“本地先掷骰、AI 后出题”的流程。用户点击“再出一题”时，应用先本地抽取真实三骰，再将已确定骰面交给 AI，请其生成相配的日常练习问题。AI 不再负责掷骰，也不能替换骰面。

用户完成自己的解读后，可获得逐骰参考、亮点、改进建议、整体点评及 1–100 分的 AI 评分。训练记录与评分可保存到档案中，帮助用户连续观察自己的表达、结构和解释能力。训练场还提供可复选题材范围与“其它”自定义范围，支持关系、职场、学习、家庭、创作、出行等不同练习方向。

### 4. 星语图库：让视觉内容与案例保持关联

用户可为完成解读的占问生成骰子主题图、海报型图片或自定义图片。图片会按照本地命名规则归档到 `data/images`，并与对应占问记录建立关联。图库提供十张分页浏览、大图查看、打开原图与另存图片功能，并会记住上次另存位置。

图片提示词模板由用户在偏好页维护。应用保留默认模板，也允许用户为不同图像类型创建更贴合自己审美与模型能力的表达方式。

### 5. 工作室偏好：集中管理模型、提示词、日志与数据

工作室偏好是《璇玑录》的控制中心。用户可在这里创建 Profile、选择文字与生图能力、调整训练出题范围、编辑图片提示词、开启模型调试日志、导出与导入 SDE-1 档案、备份数据库，或执行带多重确认的数据初始化。

初始化功能可以清空记录、训练案例、图库索引与自定义标签；用户可分别选择是否删除本地图片、Profile 设置和 Windows 凭据。该设计将不可逆操作拆分为多步确认，并要求输入“初始化”，降低误操作概率。

## 五、技术与数据设计要点

| 领域 | 当前设计 |
|---|---|
| 桌面技术栈 | Tauri 2、React、TypeScript、Rust 与 SQLite |
| 平台 | Windows x64 本地桌面应用 |
| 数据位置 | 软件安装目录下的 `data` 文件夹 |
| 档案数据库 | SQLite，本地保存占问、训练、标签、偏好与图库索引 |
| 图片保存 | 本地 `images` 目录，按规则命名并通过索引关联记录 |
| 模型密钥 | Windows Credential Manager，不进入导出包与普通日志 |
| 自动掷骰 | 后端操作系统安全随机熵源；允许自然重复，不做人工避重 |
| 训练骰面 | 先由本地随机源确定，再交给 AI 生成相配问题 |
| 导入导出 | SDE-1 ZIP、CSV、HTML、Markdown 与 SQLite 备份 |
| 调试机制 | 默认关闭；可记录调用元数据，并对敏感字段脱敏 |

## 六、产品差异化价值

《璇玑录》的差异不在于替用户选择某个固定模型，而在于提供了一套可替换、可归档、可训练的本地工作台。

首先，**骰面和档案在用户本地**。自动掷骰的最终结果不由模型语言输出决定，而由本地安全随机源抽取；训练场同样将“掷骰”与“AI 出题”解耦。其次，**模型配置由用户掌握**。用户可以根据预算、隐私偏好、服务可用性和输出风格更换文字或生图 Profile。最后，**历史能够被复盘**。占问、训练、标签、图片与个人验证并非散落在聊天记录中，而是可搜索、可导出、可备份的个人资料。

## 七、隐私与责任边界

《璇玑录》采用本地优先的存储方式，但用户选择使用 AI 功能时，问题、骰面上下文、训练文本或图片提示词会发送给用户自行配置的外部模型服务。因此，产品强调“本地档案归用户、外部模型由用户选择”的边界，也建议用户阅读所选服务商的隐私规则，谨慎输入个人敏感信息和第三方信息。

本产品用于娱乐、灵感整理与自我反思。它不应被用于替代专业医疗、法律、财务、投资、心理健康或其他需要专业判断的服务。
