问题总会在生活的转折处出现：一段关系的迟疑、一次选择的分岔、一份创作的停顿，或是那些尚未命名的内心波动。许多答案不需要被仓促给出；它们值得先被看见、被记录、被回望。

《璇玑录》将占星骰子的仪式感带到 Windows 桌面。你提出问题，掷下三颗骰子，让模型协助展开象征的语言；你也可以练习自己的解读，保存每一份案例、评分、复盘和图像。它不替你做决定，而是为你留下一张可反复阅读的星图。

### 第二屏：从一个问题开始

每一次占问，都从一个真实的问题开始。

不是仓促寻找结论，而是先让问题拥有被凝视的空间。选择自动掷骰，三颗骰子将在本地安全随机源中落定；或手动指定骰面，用于复盘、教学与再现。随后，文字模型会围绕你的问题与真实骰面展开解读，帮助你读见关系、能量与行动之间的线索。

**问题不会被替你决定。它会被更好地保留下来。**

### 第三屏：不只占问，也练习解读

《璇玑录》设有训练场。每次训练，软件先在本地抽取真实三骰，再让 AI 围绕已确定的骰面生成一道生活问题。你先写下自己的理解，再获得逐骰参考、亮点、改进建议、整体点评和百分制评分。

你可以自由选择训练题材：关系、人际、职场、成长、创作、旅行，或填写属于自己的范围。每一份训练都能保存进档案，成为可见的进步轨迹。

> **会问，是开始；会读，才是练习。**

### 第四屏：让星语留下来

一次解读，不应该在关闭窗口后消失。

星语档案帮助你保存占问、训练、标签、个人评分、复盘验证与关联图片。关键词搜索、多标签筛选、分页查看、Markdown/CSV/HTML 导出与 SQLite 备份，让每一次偶然的骰面逐渐成为可回望的个人资料。

图片也不只是即时生成的结果。它们会被归档进本地图库，与你当时的问题、骰面与解读相连。

### 第五屏：模型由你选择，档案留在本地

《璇玑录》不绑定某一家模型服务，不预置任何密钥。文字处理与生图 Profile 可分别配置；模型名称、服务地址、超时与附加参数都由你自己决定。API 密钥保存在 Windows Credential Manager，不包含在档案导出包中。

你的档案、图片和备份存放在本机；当你选择调用外部模型时，才会按你的 Profile 配置发送所需内容。

## 三、应用商店或下载页文案

### 标题

**《璇玑录》：占星骰子的本地观星台**

### 一句话简介

一款 Windows 本地占星骰子应用：自动或手动掷骰、AI 解读、解盘训练、评分复盘、图片归档与个人星语档案，模型配置由用户自己掌握。

### 标准简介

《璇玑录》是《星骰工作室》的 Windows 本地版。它以神秘的血月星盘视觉为底色，将占星骰子的占问、训练、档案与图像创作组织为连续体验。自动掷骰和训练骰面均由本地安全随机源决定；AI 用于解释已确定的骰面、生成训练题与提供点评，而不决定骰面结果。

你可以创建自己的文字与生图 Profile，保存占问、训练评分、复盘、标签与图片；导出 SDE-1 档案、Markdown、CSV 或 HTML，并在本地创建 SQLite 备份。无论是初学解盘，还是长期整理自己的星语素材，《璇玑录》都为每一次提问留下一处可回望的位置。

### 功能亮点

- **本地安全随机掷骰**：占问与训练场的最终三骰均在本机抽取，保留自然随机结果。
- **AI 星语解读**：围绕问题与真实骰面提供逐骰说明、综合解读与视觉提示语。
- **解盘训练场**：先写你的理解，再获得参考解读、亮点、改进建议与 100 分制评分。
- **可选训练题材**：关系、职场、学习、家庭、创作等范围可复选，也可填写自定义主题。
- **本地星语档案**：案例、标签、复盘、评分与图片可搜索、筛选、导出和备份。
- **星语图库**：生成、查看、打开原图和另存图片，保留与占问的关联。
- **模型自主配置**：文字与生图模型可分别设置；密钥由 Windows Credential Manager 保存。
