## 修复内容

v260825H 的“初始化”按钮调用后端命令时，独立布尔参数在运行时被错误解码，因而可能显示：

```text
invalid args `deleteImages` for command `initialize_archive`:
invalid type: map, expected a boolean
```

v260825I 将初始化参数改为一个明确的嵌套 `options` 对象。前端按以下结构提交选项，后端再以 camelCase 对应的强类型结构体解码：

```json
{
  "options": {
    "deleteImages": true,
    "deleteProfiles": false
  }
}
```

这样，“是否删除本地图片”和“是否删除 Profile 设置”会稳定作为两个布尔选项传入初始化逻辑，不再将整个调用对象误作单一布尔参数。

## 初始化功能的行为不变

初始化时仍会清空占卜记录、训练场记录、图库索引和自定义标签，并要求最后输入“初始化”确认。用户仍可选择是否删除本地图片，是否删除 Profile 及其 Windows Credential Manager 凭据。SQLite 数据库文件、数据库备份、图片提示词和调试偏好不会被删除。
