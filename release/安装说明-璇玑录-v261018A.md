# 《璇玑录》v261018A 完整安装包说明

- **版本：** v261018A（UTC+8），内部版本 0.1.18
- **平台：** Windows x64
- **安装包：** `璇玑录-v261018A-x64-完整安装包.exe`
- **SHA-256：** `68206b76d2ea7aa02467901e22291852031f7c9cd6ac53b27930e6b08bacdade`

## 安装和升级

1. 安装前完全退出《璇玑录》。
2. 如果已有旧版，建议先备份 SQLite 档案或导出 SDE-1 档案 ZIP。
3. 运行完整安装程序。需要从旧版保留数据时，在 NSIS 安装界面选择保留旧版／更新，不要选择卸载旧版后再安装。
4. 正常更新会覆盖程序文件并保留原安装目录下的 `data` 文件夹；主动卸载可能删除程序安装目录及其中的 `data` 数据。请勿手动删除该文件夹。
5. 安装完成后启动软件，检查侧栏版本为 **v261018A · UTC+8**。
6. 设置中的在线音色列表需连接 Microsoft Edge Read Aloud 服务。更新后请在目标 Windows 电脑上用短文本试播。

## 在线 TTS 验证边界

此版本采用 `edge-tts-rust 0.1.7` Sec-MS-GEC v2。构建环境已成功在线读取 322 个音色（含 6 个 zh-CN）并将测试短句合成为 MP3；但构建环境的烟测不等于你的电脑和网络已验证，也不能替代 Windows WebView2 的扬声器播放测试。若仍有错误，请记下它发生在读取音色还是合成／播放阶段及脱敏报错内容。

## 签名与 SHA-256

此包在 Ubuntu 上以 Windows GNU 目标交叉编译，NSIS 构建完整、压缩归档测试通过，但未进行代码签名；Windows 可能显示未知发布者或 SmartScreen 警告。可在 PowerShell 中运行：

```powershell
Get-FileHash .\璇玑录-v261018A-x64-完整安装包.exe -Algorithm SHA256
```

结果应为：

```text

```
