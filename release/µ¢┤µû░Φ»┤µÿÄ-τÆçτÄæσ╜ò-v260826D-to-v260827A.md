# 《璇玑录》v260827A 更新说明

> **适用补丁：** `v260826D`（内部版本 `0.1.13`）→ `v260827A`（内部版本 `0.1.14`）  
> **系统：** Windows x64  
> **发布方式：** 严格相邻差别升级包；仅更新 `xuanji-lu.exe` 主程序。

## 本次更新概览

v260827A 为《璇玑录》加入 **Microsoft Edge 在线语音朗读**。实现完全保留现有 Tauri + React + Rust 架构：后端以 Rust 直接调用在线语音客户端，不依赖 Python 运行时，也不要求用户创建 Azure Speech 资源、填写 Endpoint 或保存 API Key。

| 功能 | v260827A 行为 |
|---|---|
| 中文音色 | 在“工作室偏好 → 语音输出”点击刷新图标读取 Microsoft Edge 在线简体中文音色，并从下拉菜单选择。 |
| 占问朗读 | 在占问结果的综合解读区域提供图标式播放／停止与另存音频。朗读内容包括逐骰参考与综合解读。 |
| 训练出题朗读 | 在训练场的题目与三骰结果下方提供同样的图标式播放／停止与另存音频。 |
| 训练点评朗读 | 在训练点评、参考解读、AI 评分、亮点、可改进与整体点评下方提供同样控件。 |
| 播放控制 | 点击扬声器图标开始播放；播放期间再次点击同一图标会立即停止并回到开头。 |
| 音频另存 | 点击音频另存图标选择位置，保存为 MP3；软件会记住上次选择的目录。 |
| 历史边界 | 音频只暂存于内存，除非用户主动另存；不会写入 SQLite、星语档案、SDE-1 导出包或历史记录。 |

## 使用步骤

安装本补丁后，先打开 **工作室偏好** 页面并找到“语音输出”面板。点击“读取微软中文音色”刷新图标；联网成功后，从下拉菜单中选择一个简体中文音色。该选择会保存在本机偏好中。

返回占问结果、训练场出题或训练点评区域后，点击扬声器图标即可播放对应文本。首次播放会将本次文本提交到在线服务合成 MP3，期间显示生成状态；同一页面、同一音色与同一文本在本次窗口生命周期内会复用内存中的音频。播放开始后再次点击扬声器图标，可立即停止。若希望保留文件，请点击另存音频图标，并在系统对话框中选定 MP3 保存位置。

## 联网、隐私与稳定性边界

本功能需要网络连接。每次合成时，只有用户点击朗读所对应的文本会发送至 Microsoft Edge 在线语音服务；程序不发送文字／生图 Profile 的 API Key，不创建或保存 Azure Key，也不将合成音频自动归档到历史记录。

> Edge 在线语音不是 Azure Speech 的面向开发者稳定 API。服务端可能调整协议、音色、限流或可用性；如果将来发生此类变化，语音功能可能暂时不可用，但不会影响占问、训练、档案、图库和本地数据。

本版使用的 `edge-tts-rust` 客户端采用 MIT 许可证。[1] 其完整研究与来源记录见随发布保留的 `研究注记-Edge在线语音Rust实现.md`。

## 安装与核验

1. 完全退出《璇玑录》，包括确认任务栏通知区域没有残留主程序。
2. 运行 `璇玑录-v260826D-to-v260827A-Patch.exe`。
3. 补丁会检查注册表中的来源版本必须为 `0.1.13`，并先备份 `xuanji-lu.exe`；写入失败会尝试自动回滚。
4. 启动后，侧栏应显示 **v260827A · UTC+8**。
5. 可在发布目录执行 `sha256sum -c 璇玑录-v260826D-to-v260827A-Patch.exe.sha256` 校验文件完整性。
