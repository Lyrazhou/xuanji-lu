# 《璇玑录》v260827B 更新说明

> **适用补丁：** `v260827A`（内部版本 `0.1.14`）→ `v260827B`（内部版本 `0.1.15`）  
> **系统：** Windows x64  
> **发布方式：** 严格相邻差别升级包；仅更新 `xuanji-lu.exe` 主程序。

## 修复结论

本次修复基于 v260827A 的真实运行反馈。前版的 Edge 在线语音合成、音色读取、播放／停止与 MP3 另存逻辑已经写入，但存在两个影响使用体验的交付缺口：其一，已选择的音色写入了本地偏好，却在再次进入设置时因尚未重新取得在线音色列表而没有对应的下拉选项，视觉上呈现为空；其二，语音控件只接入了当次占问结果和当次训练页面，未接入星语档案的历史详情窗口。

v260827B 同时修复上述两项，并补足历史案例朗读。

| 项目 | v260827B 行为 |
|---|---|
| 已选音色持久化 | `ttsVoiceShortName` 会持久化于本地 meta 偏好表；后端新增回归测试验证保存后重读仍为相同音色。 |
| 重新进入设置 | 即使在线音色尚未重新加载，下拉菜单也会显示“已保存”的音色标识；若已有选择，进入语音设置后会自动尝试刷新音色列表，以恢复本地化名称、性别与完整选项。 |
| 当次占问结果 | 综合解读下方保留图标式播放／停止与 MP3 另存。 |
| 当次训练场 | 训练题目及三骰、训练点评及 AI 评分下方均保留图标式播放／停止与 MP3 另存。 |
| 历史占问详情 | 在“星语档案 → 占卜记录 → 查看”的综合解读下方新增图标式播放／停止与 MP3 另存。 |
| 历史训练详情 | 在“星语档案 → 训练场 → 查看”的参考解读与对照点评下方新增图标式播放／停止与 MP3 另存。 |

## 安装后验证

1. 完全退出《璇玑录》，运行本补丁；它只接受 `v260827A / 0.1.14` 作为来源版本。
2. 启动后，侧栏应显示 **v260827B · UTC+8**。
3. 打开“工作室偏好 → 语音输出”。之前选择过的音色应不再显示为空；联网时将自动尝试恢复完整音色名称，亦可点击刷新图标手动读取。
4. 新建一次占问并生成结果，在“综合解读”下方确认扬声器图标与下载图标可见。
5. 在训练场完成一次出题和点评，确认题目区、点评区均有同样图标。
6. 进入“星语档案”，分别打开一条占卜记录和一条训练案例，确认其详情窗口也有对应图标。
7. 点击扬声器开始朗读，再次点击同一图标应立即停止；点击下载图标后另存的 MP3 不会写回档案或 SDE-1 包。

## 数据与联网边界

本修复不改变现有 SQLite 档案、图片、备份、文字／生图 Profile、Windows Credential Manager 密钥或已另存音频。Edge 在线语音仍需联网，且仅会在用户主动播放或另存时发送相应朗读文本；不会发送既有 Profile 密钥，也不会自动把音频写入历史。
