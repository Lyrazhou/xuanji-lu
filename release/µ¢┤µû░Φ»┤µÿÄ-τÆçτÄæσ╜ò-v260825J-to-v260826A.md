## 修复：初始化“选项格式无效”

此前两种带参数的初始化调用方式仍可能受到 Tauri IPC 运行时参数映射影响，出现“初始化选项格式无效”或布尔值解码错误。

v260826A 不再通过 IPC 传递任何初始化选项。前端完成图片与 Profile 的两次确认后，直接在以下四个**零参数命令**中选择其一：

| 用户选择 | 调用的零参数命令 | 清理行为 |
| --- | --- | --- |
| 保留图片、保留 Profile | `initialize_archive_keep_assets` | 清空记录、训练、图库索引与自定义标签。 |
| 删除图片、保留 Profile | `initialize_archive_delete_images` | 在上述基础上删除本地图库图片。 |
| 保留图片、删除 Profile | `initialize_archive_delete_profiles` | 在上述基础上删除 Profile 及 Windows 凭据。 |
| 删除图片、删除 Profile | `initialize_archive_delete_all` | 同时删除本地图片、Profile 与 Windows 凭据。 |

由于这四个命令均不接受 IPC 参数，初始化操作不再依赖对象、布尔值或 JSON 字符串的运行时解析，因此消除了此前连续出现的参数解码失败路径。

数据库文件、备份文件、图片提示词和调试偏好仍不会被初始化删除。
