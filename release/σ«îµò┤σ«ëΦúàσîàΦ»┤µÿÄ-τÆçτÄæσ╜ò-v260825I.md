# 《璇玑录》v260825I 完整安装包说明

**版本：** v260825I（内部版本 0.1.8）  
**架构：** Windows x64  
**安装包：** `璇玑录-v260825I-Full-Setup-x64.exe`

本安装包包含截至 v260825I 的全部功能与修复，包括本地数据目录、图库查看权限、分页档案、图片另存、初始化操作，以及初始化命令参数修复。

## 安装方式

请先完全退出《璇玑录》，然后运行完整安装包。该完整包可用于首次安装，或覆盖安装现有版本；无需先逐级安装补丁。

| 使用情形 | 建议操作 |
| --- | --- |
| 首次安装 | 直接运行完整安装包。 |
| 已有旧版本，想保留档案 | 退出软件后直接运行完整安装包；不要手动删除数据目录。 |
| 希望从空白档案开始 | 安装后，在“工作室偏好”中使用 v260825I 已修复的“初始化”功能，并按照确认步骤选择是否删除图片和 Profile。 |
| 旧版数据仍在旧目录 | 首次启动会兼容复制旧数据；请不要在确认档案可用前删除旧目录。 |

## 本地数据位置

程序安装目录默认位于：

```text
%LOCALAPPDATA%\璇玑录
```

数据库、图库和备份位于安装目录下的专用 `data` 文件夹。Profile 密钥由 Windows Credential Manager 管理，不写入数据库、导出包或安装包。

## 初始化修复

本版修复了 v260825H 中初始化按钮可能出现的参数解码错误。初始化时，“是否删除本地图片”和“是否删除 Profile”现在会作为明确的布尔选项传给后端；仍须输入“初始化”才能执行。
