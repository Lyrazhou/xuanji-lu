# 《璇玑录》v260828A 更新说明

本次补丁处理历史记录删除保护、Edge 在线语音跨网络容错与错误提示、以及图片系统标签的持久化和历史回填。

| 反馈项目 | v260828A 处理结果 |

| 删除占卜／训练记录 | 删除前须连续通过两次确认。第二次明确提示删除后不能从软件内恢复；取消任一步骤均不会改动记录。 |

## 关于你看到的 Token 和连接失败

`trustedclienttoken` **不是《璇玑录》设置的用户密钥，不是 Azure Key，也不与具体电脑绑定**。它是所用 `edge-tts-rust` 依赖为模拟 Edge Read Aloud 协议而内置的公开客户端常量；该依赖也在每次请求时生成新的 `ConnectionId`、随机 `muid`，并根据当前时间计算 `Sec-MS-GEC`。因此，更换电脑并不会导致“固定 token 被其他设备占用”。该依赖公开说明其面向 Microsoft Edge Read Aloud 的在线语音，并提供音色读取和 WebSocket 合成能力。[1]

此次开发环境的实时测试当前仍可成功完成音色读取和中文语音合成（包括新建连接路径）。你新电脑上的“HTTP 请求发送失败”及“远程主机强迫关闭连接（10054）”更符合**该电脑所在网络路径**被代理、防火墙、安全软件、TLS 检查或网络策略中断，或系统时间偏差导致服务侧校验失败的表现。Edge 在线朗读依赖并不是 Microsoft 面向第三方承诺稳定的 Azure Speech API；上游协议一旦收紧或网络环境阻断，仍可能不可用。[1] [2]

v260828A 已把应用自身可控制的部分改为“三次独立新连接 + 不预热 + 不复用 + 更清晰且不暴露查询参数的错误”。若安装后仍在同一新电脑上连续失败，请确认 Windows 的“设置时间／自动设置时区”已开启，暂时关闭或放行安全软件的 HTTPS／WebSocket 检查，并确认网络未限制 `speech.platform.bing.com` 的 HTTPS 和 WSS 连接。其他本地功能不受这项在线服务失败影响。

## 安装与验收

1. 完全退出正在运行的《璇玑录》v260827C。
2. 运行本补丁。它会检查 Windows 安装项内部版本必须为 `0.1.16`，不接受更早或其他版本。
3. 启动后，侧栏应显示 **v260828A · UTC+8**。
4. 在“星语档案”中删除任意占卜记录和训练记录，各自应出现两次确认；在第二次确认选择取消，记录必须保留。
5. 打开“工作室偏好 → 语音输出”。已保存音色应仍显示；若在线读取失败，应在卡片内显示状态文字而非首次进入即弹出长 URL。点击刷新后会自动进行 3 次独立尝试。
6. 新建一张星语图片后，进入“星语档案”确认对应占卜记录出现蓝色“图片”标签；对过去已有图片的记录，打开或刷新档案后也应自动出现该标签。
7. 尝试播放一段语音。若新电脑网络允许 Edge 服务，应用应直接合成并播放；若仍失败，错误提示应不再含完整查询 URL，并说明要检查网络、代理／安全软件和系统时间。
