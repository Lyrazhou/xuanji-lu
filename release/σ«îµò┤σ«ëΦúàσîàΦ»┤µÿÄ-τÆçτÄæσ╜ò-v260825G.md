# 《璇玑录》v260825G 完整安装包说明

**版本：** v260825G（内部版本 0.1.6）  
**构建目标：** Windows x64  
**交付形式：** 完整 NSIS 安装包  
**用途：** 卸载旧版后重新安装，首次运行即使用软件安装目录下的 `data` 专用数据文件夹。

## 新的数据保存位置

安装后，软件主程序通常位于：

```text
%LOCALAPPDATA%\璇玑录\xuanji-lu.exe
```

数据库、图库和备份会保存于同一安装目录下的专用数据根：

| 数据 | 新位置 |
| --- | --- |
| SQLite 档案数据库 | `%LOCALAPPDATA%\璇玑录\data\xuanji-lu.sqlite3` |
| 生成图片图库 | `%LOCALAPPDATA%\璇玑录\data\images\` |
| 数据库备份 | `%LOCALAPPDATA%\璇玑录\data\backups\` |
| 调试日志 | `%LOCALAPPDATA%\璇玑录\logs\xuanji-llm-debug.jsonl`（仅启用调试开关后写入） |

“打开原图”被明确限制为只可打开 `data\images\` 内已归档的本地图片，并由 Windows 默认图片查看器接管显示。

## 重装前的两种选择

旧版本的数据通常还在：

```text
%LOCALAPPDATA%\XuanjiLu
```

请在首次启动 v260825G 前，按是否保留旧档案选择以下其中一种做法。

| 目标 | 操作 |
| --- | --- |
| **保留现有占卜、训练、图库和备份** | 卸载旧版时保留 `%LOCALAPPDATA%\XuanjiLu`。安装 G 并首次启动后，软件会将其中的数据库、图库和备份复制到新的 `data` 目录，并自动修复数据库中的图片路径。确认新版本可正常读取后，再自行保留或删除旧目录。 |
| **从空白档案开始** | 卸载旧版后，手动删除 `%LOCALAPPDATA%\XuanjiLu`，再安装并启动 G。软件会在安装目录下自动新建空的 `data\images`、`data\backups` 和数据库。 |

> API 密钥保存在 Windows Credential Manager，不属于上述目录。卸载或删除旧数据目录不会自动删除系统凭据；如需清除密钥，请先在旧版或新版的 Profile 设置中删除对应 Profile。

## 安装步骤

1. 完全退出《璇玑录》。如软件仍在运行，请先结束任务栏通知区域中的残留进程。
2. 根据上表决定保留旧数据或从空白档案开始。
3. 运行 `璇玑录-v260825G-Full-Setup-x64.exe`。
4. 使用默认当前用户安装路径完成安装。
5. 首次启动后，在“工作室偏好”确认数据目录已显示为安装目录下的 `data` 文件夹；侧栏版本应显示 **v260825G · UTC+8**。
6. 在星语图库中选择一张本地归档图片，点击“打开原图”，确认 Windows 默认图片查看器能够打开图片。
