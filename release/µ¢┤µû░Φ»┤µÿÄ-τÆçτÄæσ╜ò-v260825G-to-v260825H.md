## 新增：工作室偏好中的“初始化”

在“工作室偏好”→“本地档案与互换”面板中新增 **初始化** 按钮。该操作用于重新开始本地档案，但以分级确认避免误删：

1. 第一次确认会说明档案记录将被永久清空。
2. 第二次询问是否同时删除 `data\images` 中的本地图片文件。
3. 第三次询问是否删除全部 Profile 设置，以及 Windows Credential Manager 中与这些 Profile 对应的密钥。
4. 最后必须手动输入 **初始化** 才会执行。

| 数据类别 | 默认初始化结果 | 可选项 |
| --- | --- | --- |
| 占卜记录 | 清空 | 固定清空 |
| 训练场记录 | 清空 | 固定清空 |
| 图库索引 | 清空 | 固定清空 |
| 自定义标签 | 清空；系统“自动 / 手动 / 图片”标签会自动重建 | 固定清空 |
| 本地图片文件 | 默认保留 | 可在第二次询问中选择删除 |
| Profile 设置 | 默认保留 | 可在第三次询问中选择删除 |
| Profile 系统凭据 | 保留 Profile 时不动 | 删除 Profile 时一并删除对应密钥 |
| SQLite 数据库文件 | 保留文件本身，仅清空相关记录 | 固定保留 |
| 数据库备份、图片提示词、调试设置 | 保留 | 固定保留 |

> 若选择保留图片，图片文件会继续留在 `%LOCALAPPDATA%\璇玑录\data\images`，但其图库索引已经清空。此时可在文件系统中自行保留、另存或手动删除这些图片；软件不会自动重新关联它们。

## 安装方式

1. 完全退出软件。
2. 确认当前侧栏版本为 **v260825G · UTC+8**。
3. 运行 `璇玑录-v260825G-to-v260825H-Patch.exe`。
4. 启动后确认版本为 **v260825H · UTC+8**。
5. 仅在明确希望清空本地档案时，进入工作室偏好并使用“初始化”。
