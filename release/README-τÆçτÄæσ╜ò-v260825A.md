## 安装方式

请在 64 位 Windows 10 或 Windows 11 上运行 `璇玑录-v260825A-Setup.exe`。安装程序按“当前用户”模式安装，不需要管理员权限。安装完成后，可从开始菜单或安装目录启动《璇玑录》。

本安装包由云端交叉构建，尚未附加代码签名证书。因此 Windows 首次运行时可能展示来源提示；请在确认文件名与下方 SHA-256 校验值一致后，再按系统提示继续安装。首版建议先在一台 Windows 电脑上完成一次安装、启动、导入样例档案与卸载后的数据保留验收。

## 首次使用

《璇玑录》不内置任何模型服务或 API 密钥。没有配置模型时，仍可使用随机/手动掷骰、本地档案、复盘、评分、标签、图库浏览，以及 SDE-1 导入导出等非 AI 功能。

需要 AI 解读、训练出题/点评或星语生图时，请进入“工作室偏好”，自行创建 Profile。文字处理与生图 Profile 分开保存，并通过两个独立下拉菜单选择当前调用者。当前版本支持：

| 能力 | Profile 协议 | 完整地址示例 |
|---|---|---|
| 文字处理 | OpenAI Chat Completions 兼容 | `https://你的服务/v1/chat/completions` |
| 生图 | OpenAI Images 兼容 | `https://你的服务/v1/images/generations` |

每个 Profile 由用户定义名称、模型标识、完整 API 地址、认证方式、密钥、附加请求头与额外请求参数。密钥通过 Windows 系统安全凭据保存；它不会进入 SDE-1 档案包，也不会出现在常规导出内容中。

## 档案与图片位置

应用程序与用户档案相互分离。用户档案默认位于 Windows 本地应用数据目录下的 `XuanjiLu` 文件夹，其中包括 SQLite 数据库、`images` 图片归档目录与 `backups` 备份目录。升级补丁和卸载程序均不得删除此处的数据；涉及数据库结构变更的补丁，应先创建带时间戳的备份。

## 网页版档案导入

“星语档案”与“工作室偏好”均提供 SDE-1 导入导出入口。可直接选择网页版导出的 `星骰档案导出_yyyyMMdd.json`，也可选择 JSON 与 `images/` 文件夹打包的 ZIP 档案。导入会执行以下规则：

1. 校验 `format = star-dice-exchange` 与可支持的 `version = 1`。
2. 按标记名称合并；导入包引用但未定义的标记自动建立灰色兜底标记。
3. 按稳定 `uid` 幂等合并记录；同 UID 的记录按更新时间比较，缺少 `updated` 时回退使用 `created`。
4. 相对路径图片复制进本地 `images`；外链图片保留为原 URL。
5. 完成后显示新增、更新、跳过、创建标记与归档图片数量。

本版本已使用用户提供的 `sample-star-dice-exchange.json` 作为 SDE-1 解析回归样例，样例中的 2 条占卜、1 条训练、1 张图库图片与 2 个标记均可被解析。

## 已实现范围

v260825A 包含星骰占问、自动与手动掷骰、用户自建文字 Profile 调用、解读自动归档、用户自建生图 Profile 调用、星语图库、双标签历史档案、复盘与星级、彩色标记、训练场、SDE-1 双向导入导出、Markdown / CSV / HTML 人读导出，以及 SQLite 立即备份。

视觉基线为“血月星盘”：曜石黑、深靛、低饱和暗红与古金构成界面；首页、档案、训练场和图库均内置无文字背景资产。背景仅承担氛围，不替代信息层；长文本和表单区域始终使用深色玻璃卡以保证可读性。
