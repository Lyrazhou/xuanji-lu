# 《璇玑录》v260825B 补丁修复说明（r2）

`璇玑录-v260825A-to-v260825B-Patch-r2.exe` 是对先前同路径补丁的**替换文件**。请不要再使用未带 `r2` 后缀的旧补丁。

旧补丁通过卸载注册表项的 `InstallLocation` 推断目录，并对带引号的路径进行了错误的二次截断。在部分 Windows 环境中，这会使主程序检测落到错误路径，从而出现“已找到安装目录，但找不到主程序”的提示。

r2 补丁改为优先读取 v260825A 安装器实际写入的厂商注册表路径：

```text

```

该值保存真实安装目录，不带卸载项中可能出现的外层引号。r2 仍保留卸载项 `InstallLocation` 作为兼容回退，但只会清理其**前导**引号，不会再删除路径末尾字符。补丁内部确认目标主程序为 `xuanji-lu.exe`，并在替换前校验 v260825A 的内部版本 `0.1.0`。
