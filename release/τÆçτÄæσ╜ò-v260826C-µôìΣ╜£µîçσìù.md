# 《璇玑录》操作指南

> **适用版本**：v260826C（Windows x64，本地版）  
> **产品定位**：《星骰工作室》的 Windows 本地版  
> **数据原则**：本地优先保存；模型服务、模型名称与密钥均由用户自行配置。

## 一、开始之前

《璇玑录》是一款围绕占星骰子进行占问、训练、归档与图像创作的本地桌面应用。它将每次占问的三颗骰子、AI 解读、用户复盘、训练案例和相关图片保存在本机，帮助用户把零散的灵感沉淀为可回顾的个人星语档案。

首次启动时，应用会自动最大化窗口。左侧侧栏提供五个主要模块：**星骰占问、星语档案、训练场、星语图库、工作室偏好**。侧栏底部显示当前版本；本指南对应 `v260826C · UTC+8`。

> **使用边界**：占星骰子解读与 AI 生成内容仅用于娱乐、灵感整理与自我反思，不构成医疗、法律、财务、投资、心理诊断或人生重大决策建议。

## 二、首次设置：创建你的模型 Profile

在使用 AI 解读、训练出题、训练点评或生图前，请先进入 **工作室偏好** 创建并选择 Profile。软件不预置任何厂商、模型、服务地址或密钥；文字处理和生图使用彼此独立的 Profile。

| 配置项 | 用途 | 使用建议 |
|---|---|---|
| Profile 名称 | 方便区分不同服务或模型 | 使用清楚的名称，例如“文字解读服务”或“星语生图服务” |
| 用途 | 选择文字处理或生图 | 文字 Profile 用于解读、训练出题与点评；生图 Profile 用于生成图片 |
| 完整 API 地址 | 模型服务的请求地址 | 按服务商提供的兼容接口填写 |
| 模型名称 | 服务端实际模型标识 | 与服务商文档或控制台一致 |
| 认证方式与 API 密钥 | 用于请求模型服务 | 密钥仅保存到 Windows Credential Manager，不随档案导出 |
| 超时时间 | 单次请求最长等待时间 | 文字处理通常建议保留默认值；生图服务可根据供应商响应速度调整 |
| 额外请求参数 | 为兼容服务补充 JSON 参数 | 仅在确认服务要求时填写；同名参数可能覆盖应用默认值 |

保存 Profile 后，分别在“文字处理 Profile”和“生图 Profile”下拉框中选择当前使用的配置。未选择文字 Profile 时，骰子和本地档案功能仍可使用，但无法请求 AI 解读或训练点评；未选择生图 Profile 时，其他功能不受影响。

## 三、星骰占问：完成一次完整占问

### 1. 提出问题

进入 **星骰占问**，点击“开始占问”，输入本次想问的问题。问题越具体，后续解读越容易围绕真实情境展开。建议使用“我在某个选择中需要看见什么”“这段关系当前的互动模式是什么”一类开放而清晰的问法，而不是将应用作为替代现实决策的唯一依据。

### 2. 掷下三颗骰子

输入问题后进入掷骰步骤。你可以使用“自动掷骰”，也可以手动选择三个骰面。

| 方式 | 操作 | 骰面来源 |
|---|---|---|
| 自动掷骰 | 点击“自动掷骰”，等待短暂滚动动画结束 | 最终行星骰、星座骰和宫位骰由本地后端通过操作系统安全随机熵源抽取 |
| 手动掷骰 | 分别选择行星骰、星座骰与宫位骰面 | 由用户指定，适用于复盘、教学或复现特定组合 |

自动掷骰的界面动画仅用于呈现仪式感；动画结束时落定的三骰才是实际结果。三组骰面分别从 12 个行星、12 个星座和 12 个宫位中独立抽取，因此总共有 1,728 种完整组合。真正随机的抽样可能自然出现重复组合，应用不会为了“看起来更随机”而自动改写或重掷结果。

### 3. 请求 AI 解读

确认骰面后，点击进入解读。应用会将你的问题和实际三骰上下文发送至当前文字 Profile，并显示等待提示。通常文字请求需要约 30–60 秒，具体时间取决于你配置的模型服务。

解读结果包括三颗骰子的分项说明、综合解读和英文图像提示语。系统提示词要求模型基于**实际骰面**返回内容，不以预设骰面作为模板。完成后，这次案例会自动进入本地档案，并带上“自动”或“手动”系统标签。

### 4. 生成星语图片

如果已配置生图 Profile，可在解读完成后选择图片输出类型。应用支持骰子主题图、海报类型和自定义图片输出。海报类型为默认选项；三种类型的图片提示词模板均可在 **工作室偏好** 中查看、修改和恢复默认。

生成成功的图片会归档到本地图库，并与当前占问关联；该案例会自动增加“图片”系统标签。生图请求通常需要约 60 秒或更久。图片文件保存于应用数据目录的 `images` 子目录，数据库只保存图片索引和关联信息。

## 四、训练场：练习解盘与获得 AI 点评

训练场用于练习如何将三颗骰子串联成一段完整解读。点击“再出一题”后，应用会先在本地安全随机源中抽取实际三骰，再把已确定的骰面交给 AI，仅让 AI 生成相配的练习问题。**AI 不参与决定训练骰面。**

在左侧阅读题目与三骰后，先写下“你的解读”，再点击“提交我的解读”。AI 会返回逐骰参考解读、你解读中的亮点、可改进之处、整体点评，以及 1–100 分的百分制评分。

> **评分含义**：100 分仅表示三颗骰子均被准确、连贯且贴合问题地完整解读，并非鼓励性满分。评分用于观察练习进步，不代表任何专业资格认证。

点击“保存到档案”后，题目、三骰、你的解读、AI 点评与评分会作为训练案例保存。旧案例或历史导入案例没有评分时，会显示为“未评分”。

### 训练场出题范围

在 **工作室偏好** 的“训练场出题范围”卡片中，可以控制 AI 生成练习问题的题材。默认所有范围均不勾选，意味着提示词不添加范围约束。若勾选一个或多个范围，AI 只会从已选范围内出题，并尽量避免连续两题属于同一范围。

| 可选范围 | 示例方向 |
|---|---|
| 恋爱与亲密关系 | 暧昧、沟通、界限、关系节奏 |
| 友情与人际相处 | 朋友互动、社交距离、协作关系 |
| 家庭与居住生活 | 家庭角色、居住变化、归属感 |
| 职场与职业发展 | 项目、职业选择、团队协作 |
| 学业与能力成长 | 学习方法、技能积累、阶段目标 |
| 金钱与消费规划 | 消费习惯、资源分配、价值取向 |
| 身心状态与生活习惯 | 作息、压力、日常节奏 |
| 兴趣创作与自我表达 | 创作灵感、表达欲、个人项目 |
| 出行、旅行与环境变化 | 迁移、旅行、环境适应 |
| 个人选择与人生方向 | 选择权衡、阶段探索、目标调整 |

勾选“其它”后，会显示一个最多 15 个字的自定义范围输入框。只有在勾选“其它”且填写内容后，该自定义范围才会加入训练提示词。

## 五、星语档案：查询、复盘与导出

进入 **星语档案** 可以查看所有占问与训练案例。两个分页页签分别对应“占卜记录”和“训练场”。每页显示 10 条案例；在训练案例标题右侧可以看到“AI 评分 · xx 分”或“未评分”。

### 占卜记录的标签与复盘

占卜记录支持关键词搜索和标签过滤。多个标签同时选中时使用“与”逻辑：仅显示同时具有全部所选标签的案例。点击“查看”可打开详情窗口，阅读骰面、综合解读、关联图片、复盘验证和个人评分。

详情窗口中的“标签池”仅显示用户自定义标签。系统标签“自动”“手动”“图片”仍会显示在案例上并可用于过滤，但不可在标签池中编辑、删除或移除，以保证案例来源与图片状态保持一致。

### 导出记录

占卜记录可导出为 CSV 或 HTML；单条占卜与单条训练案例可导出为 Markdown。训练案例的 Markdown 导出会包含 AI 评分；没有评分的旧记录会标注“未评分”。

## 六、星语图库：查看与另存图片

**星语图库** 展示已归档的本地图片，每页显示 10 张。点击缩略图可打开更大的查看窗口。

| 操作 | 作用 |
|---|---|
| 查看大图 | 在应用内放大查看当前图片与关联信息 |
| 打开原图 | 使用系统默认图片查看器打开本地归档文件；应用会先验证文件属于本地图库目录 |
| 另存图片 | 选择目标位置复制图片；应用会记住上一次另存目录 |
| 分页浏览 | 图片超过 10 张时切换页面 |

如果“打开原图”提示文件不存在，请确认该图片是否仍位于应用数据目录的 `images` 子目录，或检查是否曾手动移动、删除应用数据文件。

## 七、工作室偏好：提示词、调试与数据管理

### 图片提示词模板

工作室偏好中提供骰子主题图、海报类型和自定义输出三套图片提示词模板。你可以按个人审美和所用模型的要求修改模板；前两项提供“恢复默认”操作。修改仅影响后续生成的图片，不会改写已归档图片。

### 调试日志

“模型交互调试”默认关闭。开启后，应用会在软件目录的 `logs/xuanji-llm-debug.jsonl` 记录调用时间、Profile、模型、参数键、状态、耗时和错误摘要。可选择是否同时记录请求与响应正文。

即使启用正文记录，应用仍会对 API 密钥、Token、Authorization、Secret 与 Password 等敏感字段进行脱敏，并且不会记录认证请求头。调试仅应用于故障排查；完成排错后建议关闭。

### 备份、导入与导出

| 功能 | 作用 | 密钥处理 |
|---|---|---|
| 导出 SDE-1 档案 ZIP | 导出本地案例、标签、图片索引等可交换档案内容 | 不导出 API 密钥 |
| 合并导入 SDE-1 档案 | 将兼容档案合并进入本地数据 | 不会导入 API 密钥 |
| 立即备份 SQLite 档案 | 在本地备份目录创建数据库备份 | 不包含 Windows 凭据内容 |

数据目录通常位于软件安装目录下的 `data` 文件夹，其中包含 SQLite 数据库、`images` 图片目录和 `backups` 备份目录。请不要在应用运行时直接修改数据库文件。

### 初始化本地数据

“初始化”用于清空案例内容，而不是卸载软件。操作会先要求两次确认，再要求输入“初始化”作为最终确认。

| 选择 | 会清理的内容 |
|---|---|
| 始终清理 | 占卜记录、训练记录、图库索引与自定义标签 |
| 选择删除本地图片 | 同时删除 `data/images` 中的已归档图片 |
| 选择删除 Profile | 同时删除 Profile 设置及 Windows Credential Manager 中相应密钥 |
| 保留项 | 数据库文件本身、备份文件、图片提示词与调试偏好不会因初始化而删除 |

初始化不可逆。若希望保留历史，请先使用“导出 SDE-1 档案 ZIP”或“立即备份 SQLite 档案”。

## 八、常见问题

| 情况 | 建议处理 |
|---|---|
| AI 解读或训练出题失败 | 确认已选择文字 Profile，检查 API 地址、模型名、密钥、服务配额与超时设置；需要时开启调试日志 |
| 生图失败 | 确认已选择生图 Profile，并检查所选模型是否支持当前画幅、尺寸或返回格式；可通过 Profile 的覆盖参数适配服务要求 |
| 训练题出现相同三骰 | v260826C 后最终三骰由本地安全随机源抽取；偶尔重复是自然随机结果，并不代表 AI 重复生成骰面 |
| 历史训练案例显示“未评分” | 这是旧案例的兼容显示；使用新版本完成并保存的新训练点评会附带 AI 评分 |
| 看不到训练范围设置 | 进入“工作室偏好”，在顶部 Profile 与本地档案卡片下方查找“训练场出题范围” |
| 初始化后记录消失 | 初始化会按确认范围清空记录；请从初始化前的 SDE-1 导出包或 SQLite 备份恢复 |
| 打开原图失败 | 检查图片文件是否仍存在于应用数据目录的 `images` 中，且未被外部程序移动或删除 |

## 九、隐私与安全建议

《璇玑录》采用本地优先的档案设计，但当你使用 AI 解读、训练或生图时，问题、骰面上下文、训练内容或图片提示词会发送至你自行配置的外部模型服务。请根据服务商隐私政策谨慎输入个人信息、第三方隐私信息或敏感素材。

建议定期创建 SQLite 备份，并在进行初始化、迁移、手动整理安装目录或更换电脑前导出 SDE-1 档案。API 密钥不应写入笔记、截图、导出包或调试报告；如需更换密钥，可在工作室偏好中编辑或删除相应 Profile。
