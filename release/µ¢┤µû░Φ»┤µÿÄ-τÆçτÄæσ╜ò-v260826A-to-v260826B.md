# 《璇玑录》v260826B 更新说明

> **发布版本**：v260826B（UTC+8）  
> **内部版本**：0.1.11  
> **升级来源**：仅限 v260826A（内部版本 0.1.10）  
> **发布形式**：Windows x64 严格相邻补丁，不含完整安装包。

## 本轮更新

本版首先将占卜解读的 JSON 输出示例改为中性占位符。此前示例中的“月亮 / ☽”仅用于说明字段格式，但为了避免任何模型受到示例值锚定，现已改为“实际骰面 / 对应符号”，并继续明确要求模型必须依据实际掷出的骰面返回结果。

训练场新增了可保存的**出题范围**设置。默认所有范围均不勾选，因此不会向提示词附加范围限制。用户可复选恋爱与亲密关系、友情与人际相处、家庭与居住生活、职场与职业发展、学业与能力成长、金钱与消费规划、身心状态与生活习惯、兴趣创作与自我表达、出行、旅行与环境变化、个人选择与人生方向；选择后，AI 仅会从已选范围中生成题目，并尽量避免连续两题属于同一范围。“其它”可填写不超过 15 个字的自定义范围，只有在勾选“其它”且填写内容后才会进入出题提示词。

训练场的 AI 点评现在会生成**1–100 分的百分制评分**。100 分仅表示三颗骰子均得到准确、连贯且贴合问题的完整解读。分数会与亮点、改进建议和整体点评一起保存至训练案例；星语档案的训练案例标题右侧、案例详情及 Markdown 导出均会显示该分数。旧训练案例没有评分时，会兼容显示为“未评分”。

应用启动时会自动最大化主窗口。系统自动标签“自动”“手动”“图片”继续会显示在已有记录上并可用于历史过滤，但不再出现在用户可编辑的标签池或自定义彩色标记列表中；后端也会阻止它们被编辑、删除或从已有记录中移除。

## 安装方法

1. 先完全退出《璇玑录》，包括确认任务栏通知区域没有仍在运行的程序。
2. 确认当前侧栏版本为 **v260826A · UTC+8**，且 Windows“应用和功能”中的内部版本为 **0.1.10**。
3. 运行 `璇玑录-v260826A-to-v260826B-Patch.exe`。
4. 补丁会先备份现有 `xuanji-lu.exe`；写入失败时会尝试恢复原版本。
5. 安装成功后重新启动软件，侧栏应显示 **v260826B · UTC+8**。

补丁不会改动 SQLite 档案、已归档图片、备份文件、训练范围偏好、Profile 设置或 Windows 凭据。补丁不能从 v260825J 或更早版本直接安装；如尚未安装 v260826A，请先按相邻顺序升级至 v260826A。

## 校验与已知范围

补丁的 SHA-256 值见同目录 `.sha256` 文件。已完成前端生产构建、Rust 单元测试（15 项通过）、Windows x64 交叉构建与 NSIS 补丁编译。交叉构建过程中出现的 Microsoft PDB `LNK4099` 与未签名提示均为云端 Windows 交叉构建的已知警告，未阻止产物生成。

Windows 的窗口最大化行为、训练范围提示词是否符合你所选题材，以及“打开原图”调用系统默认查看器，仍建议在实际 Windows 环境中分别验证。
