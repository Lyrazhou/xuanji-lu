# 《璇玑录》v261018A 更新说明

> **版本：** v261018A（东八区）
> **内部版本：** 0.1.18
> **交付：** Windows x64 完整安装包（NSIS）
> **升级基线：** 可覆盖安装 v260828A 或更早版本

## Edge 在线语音 v2 协议修复

本版将应用内 Rust 依赖 `edge-tts-rust` 从 0.1.3 升级并锁定到 0.1.7。该版本实现 Edge TTS 的 Sec-MS-GEC v2 令牌格式：令牌包含 CS64 与 SHA-256 两部分，请求版本前缀使用 `2-`。

音色列表 HTTPS 请求和语音合成 WebSocket 握手都由同一 Rust 库生成 v2 令牌。应用不会把文字模型或生图模型的 API Key 用作 Edge TTS 凭据，也不需要 Azure Speech Key；Edge Read Aloud 仍是独立的在线语音路径。

本次不改变用户在设置中选择的中文音色、前端播放方式、停止方式、MP3 另存行为或历史记录结构。语音音频仍仅在内存中处理，用户主动另存时才写入所选位置。

## 版本显示与数据保留

侧栏版本显示更新为 **v261018A · UTC+8**。Tauri／Rust 应用版本更新为 **0.1.18**，SDE-1 导出记录的应用版本字段也同步更新。

本安装包不携带用户数据库、图库图片、备份、Profile 或凭据。覆盖安装不会主动清理安装目录内的 `data` 文件夹；NSIS 更新模式删除的是旧程序文件，并以非递归方式移除空目录。

## 验证结果

- 前端 TypeScript 与 Vite 生产构建：通过。
- Rust 自动化测试：19 项通过，0 项失败。
- v2 令牌固定回归样本：与 edge-tts 维护方公布的抓包样本一致。
- 令牌输入包含固定 Trusted Client Token 常量；该值是协议内公开客户端常量，不是用户密钥、Azure 密钥或模型 API Key。
- 在线烟测：在本次构建环境通过 v0.1.7 完成在线音色读取（322 个音色，其中 6 个 zh-CN）和短中文文本合成（12,862 字节 MP3，约 9.8 秒）。这是云端构建环境的在线烟测，不是用户目标电脑的测试，也未验证 Windows WebView2 的实际扬声器播放；建议安装后在目标电脑／网络以短文本再试一次。
- Windows x64 NSIS 完整安装包：交叉编译和打包成功，7-Zip 归档完整性测试通过，包含主程序、4 张背景图资源、WebView2Loader.dll 和卸载器；未包含用户数据、凭据或构建缓存。SHA-256 已通过 `sha256sum -c` 独立复核。
- 构建说明：本包在 Ubuntu 24.04 上以 `x86_64-pc-windows-gnu` 交叉编译；Tauri 明确提示跨平台构建仍属实验性。安装程序未进行代码签名，因此 Windows SmartScreen 可能显示未知发布者提示。

## 安装提醒

安装前请完全退出《璇玑录》。直接运行完整安装包可覆盖旧版本；若安装向导询问是否卸载旧版，请选择保留旧版／更新（不要选择“卸载后安装”）。正常更新路径会逐项替换程序文件并保留旧安装目录中的 `data` 文件夹；主动完全卸载则可能删除该目录及其中数据。不要手动删除原安装目录中的 `data` 文件夹；建议安装前先备份档案。

如安装后仍遇到 403，请记录软件版本、错误阶段（音色列表或播放合成）、完整脱敏错误和网络环境，并在目标电脑上用短文本复测。Edge Read Aloud 是依赖网络的在线服务，服务器协议与地区／网络可用性仍可能变化。

## 文件完整性

完整安装包旁的 `.sha256` 文件包含对应 SHA-256。Linux/macOS 可在文件目录运行 `sha256sum -c '<安装包文件名>.sha256'`；Windows PowerShell 可用 `Get-FileHash <安装包路径> -Algorithm SHA256` 计算后与清单比对。

本软件仅用于娱乐、灵感整理与自我反思；AI 输出不构成医疗、法律、财务、投资、心理健康或其他专业建议。
