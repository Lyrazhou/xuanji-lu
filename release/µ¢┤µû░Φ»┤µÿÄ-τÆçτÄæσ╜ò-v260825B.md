# 《璇玑录》v260825B 更新说明

## 本次更新

本补丁根据首版验收反馈，集中优化了 AI 调用时的等待感知、占问仪式流程与星语图片输出控制。文字类模型调用在解读、训练出题与训练点评阶段均会显示“请耐心等待约 30–60 秒”；生图阶段则显示“请耐心等待约 60 秒”。这些提示在请求持续期间保留在操作按钮中，完成或报错后自动恢复。

训练场的结果区及保存的训练对照文本已把“我的解读”统一改为“你的解读”，使应用始终以对用户说话、点评用户答案的口吻呈现。封面大标题下的副句固定为单行显示。进入占问并提交问题后，三颗骰子不再预先给出随机结果，而是先以三个“尚未显现”的问号占位；只有用户自动掷骰或手动选面后，真实骰面才出现。

图片输出模块默认选择“星语海报”。在“工作室偏好”中新增“图片输出提示词”区域，用户可分别编辑并保存以下三类本地模板：骰子壁纸、星语海报与自定义图片输出。模板可使用 `{{question}}`、`{{dice}}`、`{{reading}}` 三个变量，软件在生图时会用当前占问、三骰与综合解读自动替换。软件仍不预置任何模型服务、账号或密钥。

| 项目 | v260825B 行为 |
|---|---|
| 文字模型等待 | 解读、训练出题、训练点评均提示约 30–60 秒 |
| 生图等待 | 提示约 60 秒 |
| 掷骰前状态 | 三张问号占位骰卡；不再默认显示随机骰面 |
| 图片模式默认值 | 星语海报 |
| 图片输出类型 | 骰子壁纸、星语海报、自定义图片输出 |
| 提示词编辑 | 三类模板在本机 SQLite 偏好中保存，支持 `{{question}}`、`{{dice}}`、`{{reading}}` |
| 训练场称谓 | 统一为“你的解读” |

## 使用方法

请先完全退出《璇玑录》v260825A，再运行 `璇玑录-v260825A-to-v260825B-Patch.exe`。补丁会在当前用户注册表中检查《璇玑录》的安装记录及内部版本 `0.1.0`，仅允许升级到内部版本 `0.1.1`。若未安装 v260825A、程序文件不存在或已安装其他版本，补丁会停止，不替换任何文件。

补丁只携带并替换新版主程序 `xuanji-lu.exe`，同时在替换前创建临时旧版备份；写入失败时会尝试回滚。它不会触碰 `%LOCALAPPDATA%\XuanjiLu` 下的 SQLite 档案、`images` 图片、`backups` 备份或 Windows 凭据中的模型密钥。
