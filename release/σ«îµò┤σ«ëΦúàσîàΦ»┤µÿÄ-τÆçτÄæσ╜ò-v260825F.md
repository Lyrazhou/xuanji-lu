## 图片与档案数据

生成图片以**本地文件**保存于 `%LOCALAPPDATA%\XuanjiLu\images\`，数据库 `%LOCALAPPDATA%\XuanjiLu\xuanji-lu.sqlite3` 只保存图片路径和相关案例索引。重新安装软件不会删除这两个位置的内容。

新图片文件按月份分目录，并按“生成时间、图片模式、问题摘要、记录 ID 前 8 位和图片扩展名”命名。例如：

```text
%LOCALAPPDATA%\XuanjiLu\images\202608\20260825-140000_poster_我是否应接受工作_12345678.png
```

## 安装方式

1. 完全退出《璇玑录》。如软件正在运行，先在任务栏通知区域确认没有残留进程。
2. 下载并运行 `璇玑录-v260825F-Full-Setup-x64.exe`。
3. 按安装向导完成安装；若已有旧版本，使用相同用户账户安装即可更新主程序。
4. 启动软件后，在侧栏确认版本显示为 **v260825F · UTC+8**。
