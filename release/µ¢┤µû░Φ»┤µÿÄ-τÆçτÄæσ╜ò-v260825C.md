# 《璇玑录》v260825C 更新说明

> 发布类型：从基准完整包 `v260825A` 直达的最小化补丁
> 升级路径：`v260825A → v260825C`
> 日期基准：UTC+8，2026-08-25

## 本次更新

v260825C 在延续 v260825B 全部功能修订的基础上，进一步减少 WebView 界面的浏览器式痕迹。应用内任何位置的鼠标右键菜单均被屏蔽，因此不会出现“另存为图片”“检查”等浏览器上下文菜单；同时抑制 F12、常见开发工具组合键、查看源代码组合键与浏览器缩放组合键。文本选择、键盘复制与粘贴不受影响。

“工作室偏好”的图片输出提示词区域中，**骰子壁纸模板**和**星语海报模板**各新增“恢复默认”按钮。点击后会把编辑区恢复为 v260825A 的出厂模板；随后点击“保存图片提示词”即可写入本地设置。自定义图片输出模板仍完全由用户维护，不会被恢复操作覆盖。

模型 Profile 新增“请求超时（秒）”字段，默认值为 **300 秒**。该参数可为文字 Profile 与生图 Profile 分别配置，允许范围为 10 至 1800 秒，并实际控制对应 HTTP 请求的超时。如果请求超时，软件会明确指出当前 Profile 的超时秒数，并提示用户检查服务状态或适当调高设置。旧有 Profile 升级后自动获得 300 秒默认值。

| 项目 | v260825C 行为 |
|---|---|
| 鼠标右键 | 应用内完全屏蔽上下文菜单 |
| 键盘复制 / 粘贴 | 保留 |
| 浏览器式快捷键 | 抑制 F12、开发工具、查看源代码与浏览器缩放快捷键 |
| 骰子壁纸模板 | 提供恢复出厂默认按钮 |
| 星语海报模板 | 提供恢复出厂默认按钮 |
| 自定义图片输出 | 保持用户自定义，不自动覆盖 |
| Profile 超时 | 默认 300 秒；每个文字 / 生图 Profile 单独保存；范围 10–1800 秒 |
| 超时反馈 | 显示实际秒数并提示调高 Profile 超时或检查服务 |

## 适用版本与安装

本补丁只适用于 **v260825A 完整安装包**，内部版本为 `0.1.0`。它将直接升级到 v260825C，内部版本为 `0.1.2`，包含 B 与 C 的全部改动；不需要也不应先安装 v260825B。

运行前请完全退出《璇玑录》，再执行 `璇玑录-v260825A-to-v260825C-Patch.exe`。补丁优先读取 v260825A 安装器写入的厂商注册表目录，确认主程序存在后才替换 `xuanji-lu.exe`。替换失败会尝试回滚。补丁不会修改 `%LOCALAPPDATA%\XuanjiLu` 内的 SQLite 档案、图片、备份，也不会接触 Windows 凭据管理器中的模型密钥。
