# 《璇玑录》v260827C 更新说明

> **版本：** `v260827C`（内部版本 `0.1.16`）  
> **交付：** Windows x64 完整安装包  
> **安装方式：** 正常安装即可；无便携版。

## 本次修复

本版集中修复 Edge 在线语音在《璇玑录》内无法直接播放的问题，并补足历史查询列表的快速播放入口。上一版能够成功生成并另存 MP3，表明在线合成和文件内容正常；问题发生在网络合成结束后的应用内播放阶段。原先使用 HTML 音频对象在异步网络请求返回后才调用播放，Windows 桌面 WebView 可能将这次延迟调用视为不再直接源自用户点击，从而拒绝自动播放。

v260827C 在用户点击扬声器时即初始化并恢复 Web Audio 播放上下文，随后把 Edge 返回的 MP3 在内存中解码并播放；同时明确允许内存媒体来源。这避免了将异步合成结束后的播放请求交给自动播放策略判断。语音文件仍只保留在内存中，用户点击另存时才会写入所选目录。

| 项目 | v260827C 行为 |
|---|---|
| 应用内播放 | 改为点击时解锁的 Web Audio 内存播放，修复“音频播放被系统阻止”提示的主要触发路径。 |
| 停止播放 | 再次点击同一扬声器图标，立即停止当前播放并将进度回到起点。 |
| 控件尺寸 | 结果页与历史详情的播放、停止和另存图标提升至 **42 × 42 px**；历史列表标题旁的快速播放图标为 **38 × 38 px**。 |
| 占卜查询列表 | 每条案例标题右侧新增播放／停止图标，朗读该条问题、逐骰信息与综合解读。 |
| 训练查询列表 | 每条训练题标题右侧新增播放／停止图标，朗读题目、三骰、AI 评分和参考点评。 |
| 历史详情 | 占问详情与训练详情仍保留播放／停止和 MP3 另存图标。 |
| 音频归档 | 音频不进入 SQLite、星语档案、SDE-1 导出包或自动备份。 |

## 安装与数据边界

这是**完整安装包**，但并非便携版。若覆盖安装到原有《璇玑录》目录，安装程序只部署程序文件；不会主动清空同级 `data` 内的 SQLite 档案、图库图片、备份、用户 Profile 或已保存偏好。安装前仍建议完全退出正在运行的《璇玑录》。首次启动后，侧栏版本应显示为 **v260827C · UTC+8**。

Edge 在线语音仍需要网络。只有用户主动点击播放或另存时，对应需要朗读的文本才会提交给 Microsoft Edge 在线语音服务；软件不会提交用户的文字／生图 Profile 密钥，也不会自动保存生成的音频。

## 建议验收步骤

1. 打开“工作室偏好 → 语音输出”，确认已选中文音色正常回显；联网时可自动恢复完整音色列表。
2. 在一条即时占问结果的“综合解读”下点击扬声器，合成完成后应直接从应用内播放；再次点击应立即停止。
3. 在训练场的练习题目与 AI 点评区域分别验证播放、停止和另存。
4. 打开“星语档案”，在“占卜记录”和“训练场”两个查询列表中直接点击每条案例标题右侧的扬声器，确认可播放；查看详情后还应看到播放与下载图标。
5. 点击另存图标后确认生成的 MP3 可由系统播放器打开；返回档案页面后，该音频不应作为历史附件出现。
