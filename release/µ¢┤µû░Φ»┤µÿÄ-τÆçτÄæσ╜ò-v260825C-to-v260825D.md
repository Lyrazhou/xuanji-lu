# 《璇玑录》v260825C → v260825D 更新说明

> 发布类型：最小化逐级升级补丁
> 升级路径：`v260825C → v260825D`
> 日期基准：UTC+8，2026-08-25

## 适用范围

此补丁仅适用于已安装 **v260825C** 的用户。补丁会校验当前内部版本是否为 `0.1.2`，确认后升级至 v260825D（内部版本 `0.1.3`）。运行前请完全退出《璇玑录》。补丁只替换主程序，并保留升级前的临时备份，以便在写入失败时恢复 C 版程序。

## 生图模型兼容性

v260825D 不再向所有图片模型固定发送同一组像素、画幅与返回格式参数。每个生图 Profile 会先按模型名称自动匹配安全预设，再允许用户针对服务商的差异自行覆写。

| 模型类别 | 自动尺寸 | 自动质量 | 自动响应格式 | 备注 |
|---|---:|---|---|---|
| `dall-e-3` | `1792x1024` | `standard` | `b64_json` | 使用 DALL·E 3 支持的横向尺寸，并固定单图。 |
| `dall-e-2` | `1024x1024` | `standard` | `b64_json` | 使用 DALL·E 2 支持的标准尺寸。 |
| `gpt-image-*`，含 `gpt-image-2` | `1024x1024` | 自动 | 不主动发送 | 依赖 GPT Image 默认 Base64 返回，避免附带 DALL·E 专属响应参数。 |
| 未识别的 OpenAI 兼容模型 | `1024x1024` | 自动 | `b64_json` | 作为最保守的兼容起点，可由用户覆写。 |

在“工作室偏好 → 编辑模型 Profile”中，生图 Profile 新增四项可选覆写：**图片尺寸、图片质量、输出格式、响应格式**。留空时使用软件预设；填写后优先采用用户值；“额外请求参数（JSON）”优先级最高，适用于第三方服务的特殊要求。软件也扩展了对标准 Base64、驼峰 Base64、常见兼容字段及 data URI Base64 返回的解析，并启用常见 HTTP 压缩响应的自动解码，改善 `gpt-image-2` 在兼容服务中的响应读取问题。

> 如果某第三方服务仍显示 HTTP 错误，请保留错误原文，并在对应生图 Profile 中根据服务商文档填写覆写。服务端对模型可用性、组织验证或内容审核的限制仍由服务商决定。
